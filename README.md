## Overview

High-performance batch converter for video, audio, image and document formats (FFmpeg + ImageMagick).

## ✨ Features

- Batch video, audio, image and document conversion
- FFmpeg and ImageMagick backends
- Context-menu integration
- Windows installer and one-click launcher
